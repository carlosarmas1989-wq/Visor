Visor de estudios DICOM

Selecciona la carpeta que contiene los archivos .dcm del estudio
(por ejemplo, la misma carpeta donde está este archivo), o arrástrala aquí.

No se encontró la carpeta visor_datos junto a este archivo.
Para que el estudio se abra solo, haz doble clic en Actualizar_visor.command (Mac) o ejecuta python3 visor_datos/generar.py.
Mientras tanto, puedes usar el botón “Abrir carpeta”.

Todo se procesa en tu computadora, dentro del navegador. No se sube nada a internet y funciona sin conexión.
Este visor es para consulta personal; no sustituye el informe del radiólogo ni un visor de diagnóstico certificado.

Sobre los textos en pantalla

Arriba a la izquierda: paciente y fecha. Arriba a la derecha: serie y número de imagen. Abajo a la izquierda: ventana (A = ancho, N = nivel), zoom y valor del píxel bajo el cursor. Abajo a la derecha: posición del corte, grosor y parámetros. Las letras amarillas indican la orientación (D/I = derecha/izquierda del paciente, A/P = anterior/posterior, S/Inf = superior/inferior).

La etiqueta azul de cada serie (p. ej. “FLAIR”, “Difusión”) es una interpretación automática del nombre técnico de la secuencia, solo como orientación.
